# KL E-Commerce Store

React + Vite e-commerce project.

## Run locally
1. Open a terminal in the `ecommerce` folder.
2. Run `npm install`.
3. Run `npm run dev`.

## Checkout update
- Cart now proceeds to a delivery and payment checkout page.
- Cash on Delivery is available and selected by default.
- Online Payment is a clearly labelled demo simulation only; it does not process real payments.
- Orders are saved in browser Local Storage with delivery, payment, and pending order status fields.
- Admin Dashboard files and functionality were not modified.
